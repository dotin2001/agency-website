- Cinematic storytelling.

Currently configured: Next.js, React, TypeScript, Tailwind CSS, and ESLint.
Planned dependencies must not be installed until their implementation step.

## Engineering principles

- Server Components by default.
- Client Components only when required.
- Keep client boundaries narrow.
- Progressive enhancement.
- Reusable primitives before duplication.
- Content separated from presentation.
- Motion must support storytelling.
- 3D must be selective and purposeful.
- Accessibility and performance are product requirements.
- Mobile must be intentionally designed.
- Keep UI, motion, and 3D responsibilities separated.
